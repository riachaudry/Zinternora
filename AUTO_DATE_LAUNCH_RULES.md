# Zinternora launch date behavior

The live site can be launched before the internship cohort start date is known.

Admin workflow:
1. Build and deploy the website.
2. Post the internship and collect applications.
3. Verify each student's payment.
4. When the actual internship start date is confirmed, set that date from the Admin panel.
5. The student's personalized Offer Letter is generated using that approved start date.
6. Week 1 begins on that start date; Weeks 2–4 are calculated sequentially.
7. Certificate and LOR dates are generated from the actual completion date.

No placeholder/mock dates should be shown on real student documents.
If a start date has not been set yet, the Offer Letter should remain unavailable rather than showing a fake date.
